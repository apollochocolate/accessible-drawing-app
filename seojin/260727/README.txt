260721 이벤트 로그 전용 실행본

기본 설정:
SHOW_CAMERA_WINDOWS = False
SHOW_DEBUG_OVERLAY = False

이 버전은 터미널에 실시간 상태를 계속 출력하지 않고, 의미 있는 변화만 출력합니다.

출력 예시:
[얼굴] 얼굴 인식 시작!
[얼굴] 얼굴 인식 준비 완료
[종이] 네 모서리 마커 인식 완료
[영역] 키보드 영역으로 변경
[키보드] Space 버튼 입력 (얼굴 왼쪽 클릭)
[영역] 마우스 영역으로 변경
[마우스] 더블클릭 실행 (얼굴)

종료: Ctrl+C
창을 다시 보고 싶으면 config_combined.py에서 아래처럼 바꾸세요.
SHOW_CAMERA_WINDOWS = True
SHOW_DEBUG_OVERLAY = True


[마커 로그 안정화 버전]
- 네 모서리 마커가 1~2프레임 잠깐 끊겨도 터미널에 끊김/완료가 반복 출력되지 않습니다.
- 마지막 정상 인식 후 BOARD_MARKER_LOST_GRACE_SECONDS초 동안은 이전 종이 좌표를 유지합니다.
- 값을 더 크게 하면 끊김 로그가 더 늦게 뜨고, 더 작게 하면 실제 끊김에 더 빠르게 반응합니다.

---
레이저만 인식 강화 버전
- 실행 직후 레이저를 끈 상태의 배경을 약 1.2초 저장합니다.
- 이후 현재 화면과 배경을 비교해서 새로 생긴 빨간 점만 레이저 후보로 봅니다.
- 종이에 원래 보이던 빨간 잡점/모니터 반사/프린트 색을 레이저로 오인식하는 현상을 줄입니다.

사용 순서
1. python main.py 실행
2. 터미널에 '[레이저] 배경 저장 중'이 뜨면 레이저를 끄고 종이를 그대로 비춥니다.
3. '[레이저] 배경 저장 완료'가 뜨면 레이저를 켜고 사용합니다.

설정값
- USE_LASER_BACKGROUND_FILTER = True
- LASER_BACKGROUND_CAPTURE_SECONDS = 1.2
- LASER_BG_MIN_REDNESS_DELTA 값을 올리면 더 엄격해지고, 낮추면 더 민감해집니다.
