# 맞춤형 색각보정 시스템 — Chrome Extension MVP

## 포함 기능
- 30문항 색 구별 프로필 테스트
- 테스트 결과를 `chrome.storage.local`에 저장
- 적색계열 / 녹색계열 / 청황계열 혼동 점수 기반 선택적 CSS 색상 보정
- 보정 강도 수동 조절
- 상태 텍스트(정상/주의/오류 등)에 테두리, 아이콘, 간단 패턴 추가
- 동적 DOM 변경 감지 후 재분석
- 보정 ON/OFF 및 현재 페이지 원본 복원

## 설치 방법
1. ZIP 압축을 풉니다.
2. Chrome 주소창에 `chrome://extensions` 입력
3. 오른쪽 위 `개발자 모드` ON
4. `압축해제된 확장 프로그램을 로드합니다` 클릭
5. 이 폴더(`color_assist_chrome_extension`) 선택
6. 확장 프로그램 아이콘을 눌러 `색 구별 테스트` 실행
7. 30문항을 완료하고 `이 프로필 적용` 클릭
8. 일반 웹사이트(http/https)를 열고 확장 프로그램을 켜서 테스트

## 현재 MVP 범위
- HTML/CSS 기반 DOM 요소의 텍스트색, 배경색, 테두리색
- 간단한 상태 요소에 시각 단서 추가
- 이미지, Canvas, WebGL, 동영상 프레임 내부의 색은 현재 직접 보정하지 않음
- Chrome 내부 페이지(`chrome://...`)는 보안상 확장 프로그램이 변경할 수 없음

## 주의
이 시스템의 테스트는 의료적 색각 진단을 위한 검사가 아니라,
웹페이지 개인 맞춤 보정값을 만들기 위한 프로파일링 테스트입니다.
색상 보정 알고리즘도 캡스톤 MVP용 휴리스틱이며,
추후 실제 사용자 테스트를 통해 색 변환 규칙을 조정하는 것을 권장합니다.


## v0.1.1 수정
- Manifest V3의 보안 정책(CSP) 때문에 테스트 페이지의 인라인 JavaScript가 실행되지 않던 문제를 수정했습니다.
- 테스트 로직을 `test.js` 외부 파일로 분리했습니다.


## v0.2.0 변경 사항
- Google 이미지 검색과 같은 `<img>` 요소에도 프로필 기반 색상 필터를 적용합니다.
- `VIDEO`, `CANVAS` 표시에도 같은 방식의 화면 필터를 적용합니다.
- 기존의 ✓ / ! / × 아이콘과 패턴 표시는 제거했습니다.
- 배경색 또는 테두리색이 실제로 보정된 UI 요소만 3px 외곽선으로 강조합니다.
- 팝업에 `이미지 색상 보정` ON/OFF 옵션을 추가했습니다.

### 이미지 보정 방식
현재 MVP는 성능과 범용성을 위해 이미지 픽셀을 새 파일로 재작성하지 않고
Chrome의 표시 단계 CSS filter를 사용합니다. 따라서 이미지 전체 색감이 프로필에 따라
이동하며, 추후 버전에서 픽셀 단위 선택적 보정으로 발전시킬 수 있습니다.


## v0.2.1 수정
- 정상 색각 사용자가 테스트했을 때 프로필 점수가 낮아 이미지 변화가 거의 보이지 않던 문제를 보완했습니다.
- 팝업에서 보정 강도를 직접 올리면 가장 높은 혼동 축을 기준으로 이미지 보정이 눈에 띄게 적용됩니다.
- Google 이미지 검색에서 일반 컨테이너까지 굵은 테두리가 생기던 현상을 줄이고,
  버튼·배지·작은 색상 박스 중심으로만 테두리를 강조합니다.
- 데모 확인 시 보정 강도를 100%로 올린 뒤 이미지 색상 보정 ON/OFF를 비교하면 차이를 쉽게 확인할 수 있습니다.


## v0.2.2 변경 사항
- 사용자가 제공한 30문항 정밀 색 구별 테스트로 교체했습니다.
- 기존 쉬운 테스트보다 색 차이가 더 촘촘하며 적응형 난이도를 유지합니다.
- 적색계열·녹색계열·청황계열 각각 10문항(적응형 6 + 같음/다름 4)으로 구성됩니다.
- 테스트 완료 후 `이 프로필 적용`을 누르면 결과가 `chrome.storage.local`에 저장되어 보정 프로그램에 바로 연결됩니다.


## v0.3.0 변경 사항
- 이미지 전체에 `hue-rotate` 필터를 거는 방식을 제거했습니다.
- 이미지 내부 픽셀을 분석하여 사용자의 혼동 축과 관련된 색상 영역만 선택적으로 변경합니다.
- 예: 적록 계열 프로필이면 사진 속 강한 빨강/초록 계열 픽셀을 중심으로 보정하고,
  파랑·회색·흰색 등 관련 없는 영역은 최대한 원본을 유지합니다.
- 외부 이미지는 Manifest V3 service worker에서 가져와 OffscreenCanvas로 처리한 뒤 다시 표시합니다.
- 너무 큰 이미지는 성능 보호를 위해 최대 1400px 범위로 처리합니다.
- 현재 선택적 이미지 보정은 `<img>` 요소를 우선 지원하며, 동영상/Canvas는 다음 단계로 남겨두었습니다.


## v0.3.2
- 이미지 선택적 보정 로직은 v0.3.0과 동일합니다.
- 테스트 난이도만 조정했습니다.
- 총 30문항 유지
- 축당 적응형 8문항 + 같음/다름 2문항
