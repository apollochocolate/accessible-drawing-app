맞춤형 색각보정 프로필 설정

자신의 색각 유형을 알고 있다면 유형을 직접 선택할 수 있습니다. 잘 모르겠다면 정밀 색 구별 테스트를 통해 개인 프로필을 생성할 수 있습니다.

색각 유형 선택

본인이 알고 있는 색각 유형을 선택하거나, 색각 유형을 모르는 경우 정밀 테스트를 진행하세요.

정밀 테스트 구성

1
화면 확인
밝기와 주변 조명을 일정하게 맞추고 회색 단계가 구분되는지 확인합니다.
2
적응형 다른 색 찾기
3개는 같은 색, 1개는 다른 색입니다. 맞히면 색 차이가 더 작아지고, 틀리면 다시 커집니다.
3
같음/다름 확인
두 색의 차이를 직접 판단해 우연히 찍어서 맞히는 영향을 줄입니다.
4
개인 프로필 생성
세 색 축의 혼동 정도와 권장 보정 강도를 0~100으로 저장합니다.
이 검사는 의료적 진단용 검사가 아니라 색각보정 시스템의 개인화 설정을 위한 프로파일링 테스트입니다. 색각 이상 여부의 의학적 판정에는 표준화된 임상 검사가 필요합니다.

화면 상태 먼저 확인

아래 회색 5단계가 서로 구분되도록 화면 밝기를 조정하세요. 야간 모드/블루라이트 필터는 가능하면 꺼 주세요.

높은 점수일수록 해당 색 축에서 더 큰 색 차이가 필요했다는 뜻입니다.
