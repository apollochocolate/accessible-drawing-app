정밀 색 구별 프로필 테스트

한두 개의 쉬운 색 문제로 유형을 단정하지 않고, 적색계열·녹색계열·청황계열을 여러 난이도에서 반복 측정합니다. 정답률뿐 아니라 최소 구별 난이도, 반복 일관성, 반응시간을 함께 기록해 맞춤형 보정 강도를 계산합니다.

테스트 구성

1
화면 확인
밝기와 주변 조명을 일정하게 맞추고 회색 단계가 구분되는지 확인합니다.
2
적응형 다른 색 찾기
3개는 같은 색, 1개는 다른 색입니다. 맞히면 색 차이가 더 작아지고, 틀리면 다시 커집니다.
3
같음/다름 확인
두 색의 차이를 직접 판단해 우연히 찍어서 맞히는 영향을 줄입니다.
4
개인 프로필 생성
세 색 축의 혼동 정도와 권장 보정 강도를 0~100으로 저장합니다.
이 검사는 의료적 진단용 검사가 아니라 색각보정 시스템의 개인화 설정을 위한 프로파일링 테스트입니다. 색각 이상 여부의 의학적 판정에는 표준화된 임상 검사가 필요합니다.

화면 상태 먼저 확인
